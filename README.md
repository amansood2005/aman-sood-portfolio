# Aman Sood — Portfolio

Personal portfolio inspired by the structure of [m7mad.dev](https://m7mad.dev): hero, about, skills, projects, and contact — with light/dark theme and motion.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

- Content: `src/data/content.ts` (bio, projects, skills, links)
- Photo: `public/images/aman.jpg`
- Resume: `public/docs/resume.pdf`

Update your real GitHub and LinkedIn URLs in `src/data/content.ts` if the placeholders differ.
